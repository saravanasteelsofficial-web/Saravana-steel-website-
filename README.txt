PUBLISH FREE WITH GITHUB PAGES
1. Download and extract this ZIP on your phone or computer.
2. Sign in at https://github.com
3. Create a new public repository named saravana-steel-website.
4. Open the repository and choose Add file → Upload files.
5. Upload index.html from the extracted saravana-steel-website folder.
   You may also upload README.txt.
6. Commit the files to the main branch.
7. Open Settings → Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select Branch: main and Folder: / (root), then Save.
10. Wait a few minutes. GitHub will show the public website link in Settings → Pages.
